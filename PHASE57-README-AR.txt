المرحلة 57: مركز الحملات والتصدير والفحص.
1. ارفع الملفات غير المضغوطة إلى جذر GitHub Pages.
2. خذ نسخة احتياطية وتحقق من SQL في بيئة اختبار قبل تشغيل PHASE57-OPERATIONS.sql.
3. ادخل admin.html ثم افتح مركز العمليات الموحد.
4. اختبر إضافة حملة تجريبية ونشرها وإخفاءها.
5. لا تتضمن الحزمة نسخًا احتياطيًا دوريًا آليًا، ولا تكامل واتساب الرسمي، ولا تعديل سياسات RLS العامة للمحتوى السابق.
6. لا تتضمن الحزمة استيراد CSV إلى قاعدة الإنتاج لتجنب الكتابة غير المتحقَّق منها.
