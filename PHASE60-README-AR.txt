المرحلة 60 — إصلاح أمان عرض المقالات والفعاليات
- منع إظهار قوائم المقالات والفعاليات عند فشل دالة فحص الجدولة/المراجعة.
- إضافة فحص المحتوى لصفحة تفاصيل المقال.
- إبقاء السجلات القديمة المنشورة بلا سجل مراجعة ضمن النشر الطبيعي عند عمل RPC.
- لا تعديل للحجوزات أو الصور أو حسابات الإدارة.
- ملف SQL اختياري لفرض حراسة RLS على زوار anon بعد مراجعة النسخة الاحتياطية وسياسات الوصول الحالية.
- لم يُختبر SQL أو الوصول الحي إلى Supabase.
- قد يُخفى المحتوى مؤقتًا إذا تعطل فحص Supabase: هذا سلوك حماية مقصود.
- باقي صفحات الموقع وسياسات authenticated تحتاج مراجعة إضافية قبل اعتماد الحماية الشاملة.
