PHASE37 — التحكم في إظهار/إخفاء الصفحات
1) ارفع جميع ملفات هذه النسخة إلى GitHub واستبدل الملفات المطابقة.
2) شغّل PHASE37-PAGE-VISIBILITY.sql مرة واحدة في Supabase SQL Editor.
3) افتح لوحة الإدارة > إظهار وإخفاء الصفحات.
4) لكل صفحة خياران: الصفحة ظاهرة، والرابط ظاهر بالقوائم.
الإخفاء لا يحذف الملفات ولا المحتوى.
