PHASE 6 - Slider + Media integration

1) Upload all files in this package to the GitHub repository root, replacing files with the same names.
2) In Supabase > SQL Editor, run PHASE6-SLIDER-MEDIA-INTEGRATION.sql once.
3) Open media-library.html. Any image categorized as "slider" will now appear automatically on the homepage after the updated index.html is deployed.
4) For full control, click "إضافة للسلايدر" on the media card or open admin-content.html > السلايدر, select the image from the media library, then set title/order/publish status.
5) No existing image, doctor photo, logo, disease, service, article, booking, or media record is deleted by this phase.
