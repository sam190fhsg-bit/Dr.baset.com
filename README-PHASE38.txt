PHASE38 - التحكم في ظهور المحتوى والفعاليات

- إظهار/إخفاء مستقل لكل حالة مرضية.
- فلاتر إدارة: الباطنة، الكبد، الجهاز الهضمي، المناظير، جميع الحالات.
- إظهار/إخفاء مستقل لكل مقال في المكتبة الطبية.
- إدارة الفعاليات: إضافة، تعديل، حذف، صورة، تاريخ، مكان، وصف، إظهار/إخفاء.
- الفعاليات المنشورة تظهر تلقائياً في واجهة الموقع الرئيسية عبر قسم المؤتمرات والفعاليات.
- لا يؤدي الإخفاء إلى حذف البيانات.
