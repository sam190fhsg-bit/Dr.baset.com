PHASE8 - لوحة الإدارة الموحدة
1) ارفع جميع الملفات إلى GitHub مع الاستبدال.
2) شغّل PHASE8-DASHBOARD-POLICIES.sql مرة واحدة في Supabase SQL Editor.
3) افتح admin.html وسجل الدخول.
4) admin-data.html يدير الحالات والخدمات والمقالات والأسئلة والحجوزات.
5) admin-content.html يدير السلايدر والفعاليات والفيديوهات والدوام والتواصل.
6) media-library.html يدير الصور.
لا يتم حذف الحجوزات من لوحة الإدارة.
