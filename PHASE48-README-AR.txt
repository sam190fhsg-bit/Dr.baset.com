PHASE48 — معرض صور الفعاليات والتحسينات التراكمية

إضافة وتحسين الميزات:
1- عرض آخر ست فعاليات منشورة بصورها على الواجهة الرئيسية بدل ثلاث.
2- ربط الصور المنشورة مباشرة بجدول events الحالي دون تكرار البيانات.
3- تحديث الصور تلقائيًا عند تعديل الغلاف أو نشر فعالية بعد إعادة تحميل الصفحة.
4- عرض صورة غلاف مخصصة لكل فعالية.
5- مكان بديل أنيق عند عدم توفر صورة.
6- تحسين توافق معرض الفعاليات مع الهواتف والأجهزة اللوحية.
7- ضغط الظهور عبر التحميل الكسول للصور خارج الجزء الأول.
8- معلومات التاريخ والعنوان والوصف المختصر والانتقال إلى التفاصيل.
9- رسالة واضحة في حال عدم وجود فعاليات منشورة.
10- رسالة واضحة عند تعذر اتصال قاعدة البيانات.
11- مربع بحث تفاعلي لصفحة الفعاليات.
12- البحث بالعنوان أو المكان أو الوصف.
13- ترتيب الأحدث والأقدم وبالاسم.
14- إحصاء الفعاليات المطابقة.
15- فتح صورة الفعالية بالحجم الكبير داخل الصفحة.
16- إغلاق معاينة الصورة بزر Esc أو زر الإغلاق أو النقر بالخارج.
17- دعم فتح الصور بلوحة المفاتيح.
18- تقليل الحركات حسب إعداد إمكانية الوصول.
19- تنبيه داخل لوحة إدارة الفعاليات إلى ارتباط الغلاف والنشر بالواجهة الرئيسية.
20- الحفاظ على إعدادات RLS والجداول القائمة بدون أوامر SQL جديدة.

مهم: ليست هذه شهادة بإكمال قائمة الميزات الخمسين الأصلية؛ تلك القائمة غير موجودة مرقمة في المشروع. بعض الميزات الأخرى تتطلب تجربة فعلية على Supabase.

للنشر: ارفع محتويات Dr.baset.com-main إلى جذر مستودع GitHub. لا ترفع المجلد الخارجي. افتح الواجهة الرئيسية وصفحة events.html واختبر إضافة فعالية مع غلاف ثم نشرها من admin-content.html#events.
