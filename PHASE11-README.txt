PHASE11 – Media Manager
- تحديد متعدد للصور وتحديد كل الصور الظاهرة.
- تغيير التصنيف جماعياً.
- ربط صورة أو صور بحالة مرضية من قائمة قابلة للبحث.
- تعديل سريع للعنوان وALT والوصف والتصنيف والمرض المرتبط.
- نقل فردي أو جماعي للسلة (Soft Delete).
- صور فئة doctor محمية من الحذف الجماعي، والحذف الفردي يتطلب تأكيداً إضافياً.
- الربط التلقائي القديم حسب slug ما زال متاحاً.
- لا يحتاج SQL جديداً إذا كانت سياسات PHASE8/PHASE10 مطبقة.
